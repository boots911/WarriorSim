# WarriorSim (Classic Era fork)

A webapp to simulate how a 1.12 / Classic Era DPS Warrior performs with different gear, buffs, rotations, and talents.

This is a fork of [GuybrushGit/WarriorSim](https://github.com/GuybrushGit/WarriorSim) focused exclusively on Classic Era (Season of Discovery support has been removed), with additional features:

- **Bags**: mark the gear you own to build an item pool.
- **Best Sets**: find your top 3 gear combinations from owned items, accounting for set bonuses, procs, and on-use trinket timing.
- **Upgrade Finder**: rank potential upgrades per source (raid, PvP, dungeon...) by their *real* DPS gain — the sim re-optimizes the rest of your gear around each candidate, so set-bonus tradeoffs are handled correctly.
